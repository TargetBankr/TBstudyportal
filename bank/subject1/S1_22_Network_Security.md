1. What does a Virtual Private Network (VPN) primarily provide? A) A secure and encrypted tunnel over a public network B) Automatic deletion of all browser history C) Faster hardware processing speed D) A physical connection between two offices
2. What is the term for the process of verifying a user's identity? A) Encryption B) Authentication C) Decryption D) Authorization
3. What is a proxy server primarily used for? A) Acting as an intermediary for requests from clients B) Managing local file permissions C) Physically repairing network cables D) Increasing the RAM of a computer
4. What is the primary function of a firewall in a network? A) To speed up internet connection B) To provide wireless connectivity C) To filter incoming and outgoing network traffic D) To store backup files
5. Which tool is used to remove or prevent malicious software from a computer? A) Spreadsheet B) Printer driver C) Antivirus D) Media player
6. What is the main goal of a Virtual Private Network (VPN)? A) To increase the speed of the internet B) To play online games C) To create a secure tunnel for data transmission D) To share files on a local printer
7. Which action is considered a form of social engineering where an attacker sends fake emails to steal sensitive information? A) Formatting B) Caching C) Indexing D) Phishing
8. What is the act of masking one's identity as a trusted source to deceive a user called? A) Compressing B) Spoofing C) Routing D) Broadcasting
9. Which of these is a type of malware that blocks access to a computer system until a sum of money is paid? A) Ransomware B) Compiler C) Interpreter D) Driver
10. What is the process of scrambling data into an unreadable format using a key called? A) Authorization B) Encryption C) Decodification D) Authentication
11. Which practice helps in preventing a successful phishing attack? A) Checking the URL for irregularities before entering credentials B) Always clicking links in suspicious emails C) Keeping the browser in incognito mode at all times D) Enabling automatic file downloads
12. What distinguishes a digital signature from a physical signature? A) Digital signatures are easier to forge B) Digital signatures cannot be verified by computers C) Digital signatures are only used for offline documents D) Digital signatures use cryptographic algorithms to ensure data integrity
13. What does a 'two-factor authentication' (2FA) system provide? A) An additional layer of security beyond just a password B) Automatic encryption of all sent emails C) The ability to bypass password requirements D) Faster login process
14. What is the purpose of multi-factor authentication? A) To create multiple accounts for one user B) To allow multiple users to log in simultaneously C) To provide an extra layer of security beyond just a password D) To increase the login speed
15. How does a proxy server differ from a firewall? A) A proxy only works for wireless networks B) A proxy acts as an intermediary for requests, while a firewall filters traffic C) A firewall hides the IP address of the user D) A proxy is a hardware device while a firewall is software only
16. What is the main security benefit of using HTTPS over HTTP? A) It prevents the website from being blocked B) It encrypts the data exchanged between the browser and the server C) It makes the website load faster D) It allows the user to download files without permission
17. In the context of information security, what does authorization determine? A) Who the user is B) The password complexity of the user C) What the user is allowed to do or access D) The location of the server
18. Which of the following is an example of good password hygiene? A) Using a combination of uppercase, lowercase, numbers, and symbols B) Using the same password for all websites C) Including personal details like birth dates D) Writing the password on a sticky note near the monitor
19. What happens when a digital signature is applied to an electronic document? A) The file size is permanently reduced B) The document is converted to an image format C) The file is automatically uploaded to the cloud D) The authenticity and integrity of the document are verified
20. Why is it dangerous to click on shortened links from unknown sources in emails? A) They consume too much RAM B) They increase the internet usage costs C) They always download a backup of the system D) They may lead to malicious websites or phishing pages
21. Which of these statements best describes the concept of a 'Zero-Day' exploit? A) A virus that deletes all data in zero seconds B) An attack that occurs exactly at midnight C) An exploit that only affects systems with zero free space D) A vulnerability that is exploited before a fix is available
22. Which of the following is NOT a characteristic of a secure password policy? A) Mandatory periodic password changes B) Lockout policies after multiple failed attempts C) Requiring a combination of letters, numbers, and symbols D) Allowing users to reuse the same password indefinitely
23. Which feature of a firewall allows it to block traffic based on specific port numbers? A) Data compression B) Hardware acceleration C) Packet filtering D) User profiling
24. Which of the following is NOT a method typically used to ensure data integrity during transmission? A) Packet routing B) Digital signatures C) Hashing D) Checksums
25. In security, what is the 'Principle of Least Privilege'? A) Giving users access to everything to avoid delays B) Restricting user access to only the resources necessary for their job C) Providing the same access level to all employees D) Allowing only administrators to access the internet
