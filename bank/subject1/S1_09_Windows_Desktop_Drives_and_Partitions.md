## EN
1. What is the primary area on the Windows screen that appears after the computer boots up and the user logs in? A) Start Menu B) Desktop C) Taskbar D) System Tray
2. Which component is located at the bottom of the Windows desktop by default? A) Taskbar B) Menu bar C) Title bar D) Status bar
3. What is the graphical representation of a program or file on the desktop called? A) Drive B) Folder C) Icon D) Window
4. Which menu in Windows provides access to all installed applications and system settings? A) Tools Menu B) File Menu C) Start Menu D) Edit Menu
5. Which drive letter is traditionally assigned to the primary hard disk partition in Windows? A) D: B) C: C) B: D) A:
6. What is the process of preparing a storage device for use by creating a file system? A) Compressing B) Formatting C) Partitioning D) Booting
7. Which action allows you to change the background image of the Windows desktop? A) Personalize B) Refresh C) Format D) Search
8. What is the term for a feature that turns off the display or shows moving patterns when the computer is idle? A) Sleep mode B) Screen saver C) Desktop theme D) Task manager
9. What is a logical division of a physical hard drive into separate storage areas called? A) Sector B) Partition C) Cluster D) Track
10. Which file system was commonly used in older versions of Windows and supports files up to 4GB in size? A) exFAT B) ReFS C) FAT32 D) NTFS
11. What is the purpose of a desktop shortcut? A) To store system files B) To provide a quick way to open a file or program C) To permanently delete a file D) To compress data
12. Which Windows feature allows you to pin frequently used applications to the taskbar? A) Auto-hide B) Snap C) Task View D) Pin to Taskbar
13. What is the default file system for modern Windows installations that provides improved security and file recovery? A) FAT16 B) FAT32 C) HPFS D) NTFS
14. How can you distinguish a shortcut icon from a standard file icon on the desktop? A) It cannot be moved B) It is always blue C) It has a small arrow in the corner D) It is larger in size
15. What happens when you format a drive in Windows? A) The drive is automatically partitioned B) The hardware is disconnected C) The drive capacity increases D) All data on the drive is erased
16. Which tool in Windows is used to manage disk partitions and drive letters? A) Device Manager B) Registry Editor C) Task Manager D) Disk Management
17. What is the difference between a local drive and a network drive? A) Network drives are mapped to a remote storage location B) Network drives do not use file systems C) Local drives cannot be partitioned D) Local drives are faster
18. Which of the following is an advantage of NTFS over FAT32? A) NTFS supports larger file sizes and better security B) NTFS is compatible with all OS C) NTFS is faster on floppy disks D) NTFS requires less disk space
19. What is the function of the 'Pin' feature in the Windows Start Menu? A) To hide the application B) To create a duplicate file C) To uninstall a program D) To keep an app entry visible for quick access
20. What happens to the desktop icons when you set the view setting to 'Auto arrange icons'? A) Icons are hidden B) Icons align to a grid on the left C) Icons are sorted alphabetically D) Icons are deleted
21. Which key combination is often used to open the Start menu if the mouse is not available? A) Alt + F4 B) Ctrl + Alt + Del C) Windows Key D) Ctrl + Esc
22. Which of these is a valid reason to partition a hard drive? A) To change the monitor resolution B) To increase the RAM C) To separate the operating system from personal data D) To increase the CPU clock speed
23. Which of the following is NOT a standard folder found on the Windows desktop? A) System BIOS B) This PC C) Control Panel D) Recycle Bin
24. If a drive is formatted with FAT32, what is the maximum size of a single file that can be stored on it? A) 16 GB B) 8 GB C) 4 GB D) 2 GB
25. What is the result of deleting a shortcut icon from the desktop? A) The folder is moved to the recycle bin B) Only the pointer to the file is removed C) The application is uninstalled D) The original file is deleted
26. Which of the following statements about drive letters in Windows is true? A) The system drive letter C: cannot be changed while Windows is running B) A drive letter is only required for network drives C) Drive letters are permanently hardcoded by the BIOS D) Drive letters can be changed for all partitions
27. Which registry hive or configuration file is responsible for storing desktop icon positions? A) NTUSER.DAT B) SECURITY C) SYSTEM D) SAM
28. What does the 'Quick Format' option do compared to a regular format? A) It encrypts the entire partition B) It scans for bad sectors C) It compresses the drive data D) It only deletes the file index and does not check for bad sectors
29. Which of the following describes the difference between a folder and a partition? A) Partitions are for files, folders are for programs B) Folders are physical, partitions are logical C) There is no difference D) Folders exist within a partition, partitions are divisions of the physical disk
