1. Which field in an email is used to send a copy of the message to additional recipients without them being visible to others? A) Bcc B) Subject C) Cc D) To
2. Which folder in an email client stores messages that have been composed but not yet sent? A) Sent B) Inbox C) Drafts D) Spam
3. What does the 'To' field in an email represent? A) The secret recipient B) The primary recipient C) The subject description D) The attachment location
4. Which of these is a common email service provider? A) Mozilla Firefox B) Google Mail C) Adobe Reader D) Windows Explorer

9. Which of the following is a platform for social media? A) Microsoft Word B) WinRAR C) Notepad D) Twitter
10. What is an 'attachment' in the context of email? A) A file sent along with the email message B) The recipient address C) The signature at the end of an email D) A folder for deleted items
11. When you click 'Reply All', the email is sent to: A) The sender and all original recipients B) Only the Cc recipients C) Only the sender D) The Bcc recipients only
12. Which of the following is a characteristic of e-commerce? A) Buying and selling goods online B) Physical banking transactions C) Government policy making D) Offline software installation
13. What happens if you delete an email from the Inbox? A) It is moved to the Drafts folder B) It is returned to the sender C) It moves to the Trash or Deleted Items folder D) It is permanently erased immediately
14. Why is 'Bcc' used instead of 'Cc'? A) To speed up delivery B) To prevent spam filters from blocking the mail C) To hide recipient addresses from each other D) To encrypt the message
15. Which of these is NOT a function of an email client? A) Operating computer hardware drivers B) Drafting messages C) Scheduling emails to be sent later D) Organizing mail into folders
16. What is the function of the 'Subject' line in an email? A) To briefly summarize the content of the message B) To attach files C) To specify the recipient D) To set the priority of the mail
17. Which technology enables secure online banking transactions? A) Encryption B) Data compression C) File archiving D) Screen recording
18. What is the primary purpose of a digital signature in e-governance? A) To automatically reply to messages B) To reduce the file size C) To make the email colorful D) To ensure authenticity and integrity of the document
19. Which of the following is a standard procedure to keep an email account secure? A) Using the same password for all websites B) Sharing passwords with friends C) Enabling two-factor authentication D) Opening all email attachments
20. Which of the following describes an 'email thread'? A) The connection speed of the email server B) A list of all email providers C) The file size limit of an email D) A series of replies grouped by the subject line
21. In an email transmission, what does SMTP stand for? A) Standard Message Transmission Process B) Secure Mail Transfer Program C) System Mail Technical Protocol D) Simple Mail Transfer Protocol
22. If you receive an email with an attachment that you were not expecting, what is the best practice? A) Forward it to all your contacts B) Delete it without opening to avoid potential malware C) Open it immediately to check content D) Reply to the sender for their bank details
23. Which of the following is NOT a valid component of a standard email header? A) Date B) To C) From D) OperatingSystem
24. What is the difference between 'Cc' and 'Bcc' when sending an email to a group? A) Cc is private, Bcc is public B) Cc requires a password, Bcc does not C) Cc is for images, Bcc is for text D) Cc is public, Bcc is private
