# MOCK: Windows, Networking and Computer Fundamentals - Servers

## EN
1. Which of these is a classic example of a client-server relationship? A) A web browser requesting a page from a web host B) A router connecting two different ISPs C) Two printers sharing a single computer D) Two PCs directly connected via a serial cable
2. When a user requests a webpage, the computer running the browser acts as the: A) Host B) Client C) Server D) Gateway
3. A server that primarily provides a central location for users to store and access documents within a network is called a: A) Proxy server B) Database server C) Web server D) File server
4. Which server type is designed to store, manage, and retrieve large amounts of structured data for applications? A) Mail server B) Print server C) Database server D) File server
5. In a client-server architecture, what is the primary role of the client? A) To provide resources to others B) To manage network traffic C) To request services from a server D) To act as a central storage unit
6. Which device acts as an intermediary between a user's computer and the internet to filter content or provide caching? A) Proxy server B) Database server C) File server D) Print server
7. Which server is responsible for managing multiple users sending documents to a single networked printer? A) Database server B) Mail server C) Print server D) Web server
8. What does a network server provide that a standalone computer does not? A) A graphical user interface B) Centralized data management for multiple users C) Internal hardware storage D) The ability to run local applications
9. Which server is most likely to contain an SQL-based engine for structured data retrieval? A) Web server B) Proxy server C) Database server D) Print server
10. Which of the following scenarios describes the use of a File server? A) A user saves a shared document to a central network folder B) A user accesses a secure webpage C) A user logs in to read their personal emails D) A user sends a command to a network printer
11. Which server is optimized to run applications that use Structured Query Language (SQL)? A) File server B) Database server C) Proxy server D) Web server
12. Which of the following best distinguishes a Database server from a File server? A) Database servers manage structured data queries while File servers manage file storage B) File servers are faster than Database servers C) Database servers require no client software D) Database servers only store images while File servers store text
13. Which scenario best describes the function of a Web server? A) Storing backups of user documents B) Delivering HTML files and images to a client browser C) Managing a shared office printer D) Storing customer bank account records for queries
14. Which of the following is a classic example of a client-server relationship? A) A keyboard connected to a computer B) A printer connected directly to a computer via USB C) Two computers sharing files via a peer-to-peer connection D) A web browser accessing a website
15. A user accesses an online banking application. In this interaction, the database containing account balances is stored on which type of server? A) Print server B) Proxy server C) File server D) Database server
16. What is the main advantage of using a dedicated File server in an office network? A) It removes the need for a network switch B) It automatically installs software on client machines C) It increases the processing speed of client computers D) It provides centralized backup and shared data access
17. When a user visits a website, their web browser acts as a client, while the computer hosting the website files acts as the: A) Web server B) Proxy server C) Database server D) Print server
18. Which of the following tasks is typically performed by a Mail server? A) Storing and forwarding electronic messages B) Managing access to shared hardware C) Hosting corporate websites D) Executing SQL queries
19. In a network, if a database server fails, what is the immediate impact on the client applications? A) The printer will stop working B) The file sharing service will be disconnected C) The application will be unable to retrieve or save data D) The browser will lose internet access
20. Which type of server would be responsible for resolving a domain name like google.com into an IP address? A) DNS server B) Mail server C) Web server D) Database server
21. Why might a Proxy server be used to improve performance in a network? A) By encrypting all database traffic B) By acting as a hardware firewall for printer traffic C) By caching frequently accessed web content to reduce external bandwidth D) By managing the physical connection of network cables
22. In a scenario where a company uses a central server to push software updates to all office computers, the server acts as: A) A Database server B) An Application distribution point C) A Proxy server D) A Print server
23. Which server configuration would be most vulnerable if the primary security policy is that only internal users can access files? A) A File server requiring multi-factor authentication B) A File server with restricted user permissions C) A File server with encrypted drives D) A File server placed outside the corporate firewall
24. Which server type would NOT be required in a simple network where users only need to share a single central printer and access the internet? A) Proxy server B) Print server C) Web server D) Database server
25. A proxy server can improve browsing performance by performing which of the following? A) Assigning IP addresses to new network devices B) Storing copies of frequently accessed web pages locally C) Encrypting all outgoing email traffic D) Converting domain names to IP addresses
