A) Ensuring the final file size can be mathematically calculated precisely before encoding begins B) Allocating more data bits to complex, fast-motion scenes and fewer bits to static scenes to optimize quality and file size C) Forcing all video frames to render at an identical resolution D) Eliminating the need for any audio codec during playback
