# MOCK: Windows, Networking and Computer Fundamentals - Setting and Protection of Computer Room and Computer

## EN
1. What is the recommended temperature range for an ideal computer room environment? A) 0 to 10 degrees Celsius B) 40 to 50 degrees Celsius C) 20 to 24 degrees Celsius D) Above 60 degrees Celsius
2. Which device provides temporary power to a computer system during a sudden electricity outage? A) Surge Protector B) UPS C) Earthing wire D) Voltage Stabilizer
3. What is the primary purpose of earthing in a computer installation? A) To prevent electric shock and protect hardware from surges B) To reduce the monitor brightness C) To increase processing speed D) To improve internet connectivity
4. Which of the following is an anti-static precaution when handling computer components? A) Working on a carpeted floor B) Keeping the computer powered on C) Using a rubber mat D) Wearing a grounded wrist strap
5. What is the main goal of ergonomics in a computer workplace? A) To increase the aesthetic appeal of the office B) To speed up data entry processes C) To optimize the comfort and health of the user D) To maximize power consumption
6. Which type of security protects a computer against unauthorized physical access? A) Firewall B) Biometric locks C) Antivirus software D) Password protection
7. What is the primary function of a surge protector? A) To provide backup power B) To protect equipment from voltage spikes C) To regulate room humidity D) To convert AC to DC
8. Why is high humidity generally considered bad for a computer room? A) It causes components to overheat B) It drains the CMOS battery C) It slows down the CPU clock speed D) It can lead to corrosion and short circuits
9. Which of these is considered a 'soft' security measure? A) Door alarms B) CCTV cameras C) Data encryption D) Cable locks
10. What is the primary purpose of regular software updates provided by operating system vendors? A) To disable keyboard shortcuts B) To patch security vulnerabilities C) To change the desktop wallpaper D) To increase physical RAM
11. When setting up a computer room, why should direct sunlight on the monitor be avoided? A) It causes glare and visual fatigue B) It damages the network cable C) It increases the power bill D) It makes the mouse click slower
12. What happens if a computer's power supply voltage fluctuates significantly without a stabilizer? A) The computer runs faster B) The operating system automatically updates C) The monitor resolution increases D) The motherboard or power supply may be damaged
13. Which of the following is the most effective way to ensure data availability in case of a system crash? A) Updating the device drivers B) Maintaining off-site backups C) Defragmenting the hard drive D) Running an antivirus scan
14. What is the main difference between an active and a passive cooling system in a server room? A) Active uses fans/AC, passive uses layout and heat sinks B) Active is for laptops, passive is for desktops C) Active uses water, passive uses oil D) Active is cheaper, passive is more expensive
15. Why should cables in a computer room be organized and managed using trays or ties? A) To increase the voltage capacity B) To allow for faster file transfer C) To improve signal transmission speed D) To prevent tripping hazards and maintain airflow
16. What is the main benefit of using a strong password combined with multi-factor authentication? A) It removes the need for antivirus B) It makes the computer boot faster C) It prevents unauthorized access even if the password is stolen D) It encrypts the hard drive automatically
17. Which of these is a preventive maintenance task for a computer? A) Overclocking the processor B) Changing the desktop theme daily C) Cleaning dust from internal fans and vents D) Reinstalling the OS every week
18. Which of the following describes the difference between a surge protector and a stabilizer? A) They are identical in function B) Stabilizer is for software, surge protector is for hardware C) Surge protector regulates voltage, stabilizer blocks spikes D) Stabilizer regulates voltage, surge protector blocks high-voltage spikes
19. What is the primary reason to use a firewall in a networked computer environment? A) To organize network cables B) To provide backup power to the router C) To manage network traffic based on security rules D) To monitor the CPU temperature
20. In the context of computer room safety, what type of fire extinguisher is recommended for electrical fires? A) CO2 or Clean Agent B) Water-based C) Foam-based D) Acid-based
21. Which of the following is NOT a recommended practice for physical data security? A) Restricting access to the computer room B) Keeping the administrator password on a sticky note under the keyboard C) Storing backup drives in a fireproof safe D) Locking the server room door
22. What is the 'cold aisle / hot aisle' concept in a data center? A) A method for physical security access B) A method to manage room lighting C) A technique for cable management D) A layout strategy to optimize cooling efficiency
23. What is the purpose of a 'Faraday cage' in the context of high-security computing? A) To block electromagnetic interference and signals B) To prevent overheating C) To store backup tapes D) To organize network routers
24. Which of the following statements about UPS systems is technically accurate? A) An online UPS converts power from AC to DC and back to AC continuously B) A UPS increases the RAM capacity C) A UPS replaces the need for earthing D) An offline UPS provides constant power conditioning
