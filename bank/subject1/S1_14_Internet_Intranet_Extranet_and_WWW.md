18. What is the function of a web server? A) To store websites and deliver them to browsers upon request B) To create images for web pages C) To translate machine language to human language D) To act as a physical bridge between two computers

21. In the context of the WWW, what is a '404' error? A) A connection timeout B) A server overload message C) An unauthorized access warning D) A page not found error
22. What does a 'DNS' server do when you type a URL into a browser? A) It encrypts the data B) It manages the download speed C) It checks for viruses on the webpage D) It translates a domain name into an IP address
23. Which of the following describes a 'dead link'? A) A link that contains a virus B) A link that points to a server that is currently offline C) A link that leads to a page that no longer exists D) A link that has been blocked by the firewall
