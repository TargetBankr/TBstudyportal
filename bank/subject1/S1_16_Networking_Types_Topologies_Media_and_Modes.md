# MOCK: Windows, Networking and Computer Fundamentals - Networking - Types, Topologies, Media and Modes

## EN
1. In which topology are all devices connected in a single continuous cable? A) Tree B) Bus C) Star D) Mesh
2. A ring topology connects devices in which shape? A) Star-like B) Linear C) Grid D) Closed loop
3. What is the primary function of a network topology? A) To install the operating system B) To determine the speed of the processor C) To define the physical or logical layout of a network D) To define the power consumption of devices
4. Which network type covers the smallest geographical area, typically within a single room? A) WAN B) PAN C) MAN D) LAN
5. In which topology are all nodes connected to a central hub or switch? A) Mesh B) Star C) Ring D) Bus
6. Which transmission mode allows data to flow in both directions, but only one direction at a time? A) Half Duplex B) Multiplex C) Full Duplex D) Simplex
7. What is the primary characteristic of a Bus topology? A) Every device is connected to every other device B) Every device is connected to a central server C) All devices share a single communication line D) Devices are connected in a closed loop
8. Which of these is a wireless transmission medium? A) Coaxial cable B) Satellite C) Twisted pair D) Fiber optic
9. What does LAN stand for? A) Large Area Network B) Local Area Network C) Limited Access Network D) Logical Access Network
10. In which transmission mode can data travel in both directions simultaneously? A) Full Duplex B) Semi Duplex C) Simplex D) Half Duplex
11. Which topology uses a central cable called a backbone? A) Star B) Ring C) Bus D) Mesh
12. Which cable type uses light pulses to transmit data? A) Shielded copper B) Coaxial cable C) Twisted pair D) Optical fibre
13. In network terminology, what is a 'node'? A) A connected device B) A transmission speed C) A cable D) A type of software
14. Which of the following describes a Tree topology? A) A combination of bus and star B) A single central server C) A loop of nodes D) A grid of routers
15. What distinguishes a hybrid topology from others? A) Requires a mainframe B) Uses only wireless links C) Uses only fiber optics D) Combines two or more different topologies
16. Which topology structure is most prone to data collisions in basic configurations? A) Star B) Mesh C) Tree D) Bus
17. What is the geographical scope of a WAN? A) A country or continent B) A single building C) A city D) A personal workspace
18. In a ring topology, what happens if one node fails? A) The whole network goes down B) The network automatically switches to star C) The data bypasses the failed node using a backup path D) Only the failed node loses connection
19. Which transmission mode is used by a standard television broadcast? A) Triplex B) Simplex C) Full Duplex D) Half Duplex
20. What is a major disadvantage of a fully connected mesh topology? A) It cannot support wireless devices B) It has no fault tolerance C) It requires too many physical cables D) It is too slow
21. Which networking device is typically at the center of a star topology? A) Repeater B) Modem C) Bridge D) Switch or Hub
22. Bluetooth is an example of which type of network? A) MAN B) WAN C) PAN D) LAN
23. What is the main advantage of a tree topology? A) Requires no central switch B) No single point of failure C) Simple to manage and expand D) Low cost of installation
24. What is the difference between coaxial cable and twisted pair? A) Coaxial has better shielding against noise B) Twisted pair uses light C) Coaxial is cheaper D) Twisted pair is immune to interference
25. In a half-duplex system, which of the following is a common example? A) Keyboard input B) Telephone C) Television D) Walkie-talkie
26. What is a Hybrid topology? A) A network that only connects two computers B) A topology that uses only wireless media C) A combination of two or more different topologies D) A topology with no central controller
27. Which network type is specifically designed to cover a city? A) LAN B) WAN C) PAN D) MAN
28. Why is Wi-Fi considered a shared medium? A) It is limited to a single user B) It requires a cable connection C) Multiple devices use the same radio frequency band D) It only works in a star configuration
29. Which topology requires a token to transmit data to prevent collisions? A) Bus B) Mesh C) Ring D) Star
30. What is the primary purpose of a microwave transmission system? A) Underwater fiber communication B) Long-distance wireless line-of-sight communication C) Short-range cable communication D) Internal computer bus communication
31. Which of these is a characteristic of a peer-to-peer network? A) All nodes have equal status B) It is more secure than a server-based network C) It is only used in WANs D) There is a dedicated server
32. Which topology provides the highest level of redundancy? A) Star B) Tree C) Bus D) Mesh
33. What is the main drawback of bus topology? A) Single point of failure at the backbone B) Complex setup C) Too many switches required D) High cost
34. Which statement correctly describes the difference between MAN and WAN? A) MAN covers a country while WAN covers a city B) WAN is always faster than MAN C) MAN is restricted to a building D) MAN covers a city and WAN covers larger geographical areas
35. What is the role of a terminator in a bus topology? A) To connect the bus to a server B) To increase the data rate C) To amplify the signal D) To absorb signals at the end of the cable
36. Which of the following is NOT an advantage of fiber optic media? A) Long distance transmission B) Immunity to electromagnetic interference C) Low cost of cable installation D) High bandwidth
37. In a star topology, if the central hub fails, what happens to the network? A) The network changes to a bus topology B) The entire network stops functioning C) The network continues to work via an alternate path D) Only the nearest node fails
38. What is the key difference between a logical topology and a physical topology? A) They are identical in meaning B) Physical is the layout, logical is the data flow path C) Physical is how it works, logical is how it looks D) Logical refers only to wireless networks
39. Which of these media is most susceptible to electromagnetic interference? A) Unshielded twisted pair B) Microwave C) Satellite D) Optical fibre
40. In a half-duplex communication, which hardware component is essential to coordinate traffic? A) A fiber-optic splitter B) A flow control mechanism C) A simple bridge D) A high-speed router
