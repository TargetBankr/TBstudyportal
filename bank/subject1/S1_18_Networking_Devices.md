# MOCK: Windows, Networking and Computer Fundamentals - Networking Devices

## EN
1. What is the full form of NIC in computer networking? A) Network Integrated Connection B) Network Internal Cable C) Network Interface Controller D) Node Interlink Circuit
2. Which networking device is used to connect multiple computers in a LAN to form a single network segment? A) Router B) Gateway C) Repeater D) Hub
3. What is the primary function of a repeater in a network? A) To connect different networks B) To assign IP addresses C) To boost and regenerate a signal D) To filter data traffic
4. Which device is commonly used to connect two different types of networks, such as a LAN to the Internet? A) Hub B) Switch C) Gateway D) Bridge
5. What is the standard connector type used with twisted-pair Ethernet cables? A) DB9 B) BNC C) USB-C D) RJ45
6. Which device acts as a modem to convert digital data into analog signals for telephone lines? A) Bridge B) Router C) Switch D) Modulator-Demodulator
7. Which device operates at the Data Link layer and forwards data frames only to the intended destination port? A) Repeater B) Router C) Hub D) Switch
8. What tool is used to attach an RJ45 connector to an Ethernet cable? A) Crimping tool B) Soldering iron C) Stripper D) Cable tester
9. Which networking device is primarily used to connect two network segments of the same type? A) Hub B) Router C) Bridge D) Modem
10. An access point is primarily used to provide which type of network connectivity? A) Wired B) Fiber optic C) Serial D) Wireless
11. What is the color standard for an Ethernet straight-through cable when both ends are wired the same? A) T568A or T568B B) T100 C) Category 7 D) BNC
12. Which device is often called an intelligent hub because it learns the MAC addresses of connected devices? A) Switch B) Repeater C) Router D) Bridge
13. What does the acronym 'LAN' stand for? A) Local Area Network B) Local Access Node C) Limited Area Network D) Large Area Network
14. Which device is used to route data packets between different IP networks? A) Hub B) Switch C) Repeater D) Router
15. What is the main purpose of an Ethernet cable? A) To store data B) To cool the CPU C) To provide power D) To connect network devices
16. What is the primary difference between a hub and a switch? A) Hub is faster B) Switch is more secure C) Hub supports more devices D) Switch has no physical ports

18. Which device is best suited to connect two computers directly without a switch? A) Cross-over cable B) Straight-through cable C) Repeater D) Bridge
19. A hub operates at which layer of the OSI model? A) Transport Layer B) Physical Layer C) Data Link Layer D) Network Layer
20. What is the main reason to use a switch instead of a hub in a busy office network? A) Reduced data collisions B) Smaller physical size C) Simpler setup D) Lower power consumption
21. Which of the following describes the function of a router in a network? A) It broadcasts data to all ports B) It connects devices within a single broadcast domain C) It amplifies electrical signals D) It uses IP addresses to determine the best path for data
22. What happens when a data frame is sent to a hub? A) It is discarded B) It is encrypted C) It is sent to all connected ports D) It is sent only to the destination device
23. What does 'Auto-MDIX' do in modern network switches? A) Encrypts traffic B) Automatically detects cable type C) Filters spam D) Increases bandwidth
24. Which device would you use to extend the range of a Wi-Fi signal in a large house? A) Repeater or Access Point B) Hub C) Bridge D) Switch
25. Why is a straight-through cable used for connecting a computer to a switch? A) It is cheaper B) The switch has internal crossover circuitry C) It prevents signal loss D) It supports higher voltage
26. What is the primary function of a modem in an Internet connection? A) Switching frames B) Converting digital and analog signals C) Routing data D) Amplifying signals
27. Which of the following is an advantage of using a router over a switch? A) Router connects different networks B) Router does not need power C) Router is faster in a LAN D) Router requires no configuration
28. In networking, what is 'collision domain' most associated with? A) Gateways B) Hubs C) Routers D) Modems
29. What is the primary role of a bridge in a network? A) Routing packets to the internet B) Connecting wireless devices C) Segmenting a network to reduce traffic D) Assigning IP addresses
30. Which of the following is NOT a feature of a switch? A) Full-duplex communication B) Broadcasting frames to all ports C) MAC address learning D) Port-based security
31. Which device is used to connect a network to the wider internet and typically performs NAT? A) Hub B) Repeater C) Router D) Bridge
32. Which of these devices creates a single collision domain? A) Switch B) Hub C) Bridge D) Router
33. If a user wants to connect a router to a switch, which cable is standard? A) Cross-over B) Coaxial C) Straight-through D) Serial
34. What is the main distinction between a gateway and a router? A) Gateway handles protocol conversion B) Router handles protocol conversion C) Gateway is always wireless D) Router is only for fiber
