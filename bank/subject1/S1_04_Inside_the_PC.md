# MOCK: Windows, Networking and Computer Fundamentals - Inside the PC

## EN
1. Which component is responsible for holding the CPU in place on the motherboard? A) DIMM slot B) CPU socket C) PCIe slot D) SATA port
2. Which of these is a slot on the motherboard used for memory modules? A) PS/2 slot B) VGA slot C) IDE slot D) DIMM slot
3. What is the primary function of the SMPS in a desktop computer? A) Convert AC voltage to DC voltage B) Store permanent user files C) Cool the processor D) Process graphical data
4. Which component is used to attach a CPU to the motherboard? A) PCI slot B) Socket C) DIMM slot D) SATA port
5. What does the cooling fan inside a computer cabinet primarily do? A) Dissipate heat generated by components B) Connect the keyboard C) Increase processing speed D) Provide power to the hard drive
6. Which of these is a standard slot used for adding internal expansion cards like sound cards or network cards? A) USB B) SATA C) PCI D) IDE
7. Which hardware component is directly attached to the CPU to help manage its temperature? A) Hard drive B) Heat sink C) Power supply D) RAM
8. What is the full form of POST in the context of computer booting? A) Primary Operational System Task B) Processor Output System Timer C) Pre-Operating Software Tool D) Power On Self Test
9. Which type of booting refers to restarting the computer without turning off the power? A) Full boot B) Hard boot C) Warm boot D) Cold boot
10. Which expansion slot is specifically designed for high-performance graphics cards? A) DIMM B) SATA C) PCIe D) IDE
11. What is the purpose of a device driver? A) To power the hardware B) To store data permanently C) To protect the hardware from viruses D) To act as an interface between OS and hardware
12. Which term describes the ability of an operating system to automatically configure new hardware? A) Plug and Play B) Cold Boot C) Overclocking D) Hardware Sync
13. Which component stores the configuration settings of the BIOS/UEFI when the computer is turned off? A) Cache memory B) Hard disk drive C) CMOS memory D) Virtual memory
14. What is the advantage of using a modular SMPS in a PC cabinet? A) Allows removal of unused cables to improve airflow B) Reduces the need for a cooling fan C) Automatically updates the BIOS firmware D) Increases the clock speed of the RAM
15. Which of these describes the function of the Northbridge in older motherboard architectures? A) Stored the permanent firmware B) Provided power to the optical drives C) Managed low-speed devices like keyboard and mouse D) Connected the CPU to high-speed components like RAM
16. In computer terminology, what is a cabinet? A) The motherboard chipset B) A type of cooling fluid C) The BIOS storage area D) The chassis holding internal components
17. Which interface is primarily used to connect modern hard drives and SSDs to the motherboard? A) SATA B) VGA C) PS/2 D) PCI
18. What is the main difference between BIOS and UEFI? A) UEFI supports larger drives and faster boot times B) UEFI is only for mobile devices C) BIOS is faster than UEFI D) BIOS has a graphical user interface
19. What happens if the heat sink is detached while the computer is running? A) The RAM will stop working B) The CPU may overheat and trigger a shutdown C) The BIOS will be reset D) The system will speed up
20. Which of these describes the function of the RAM slot on a motherboard? A) Providing power to the CPU B) Storing the BIOS settings C) Holding memory modules D) Connecting the hard drive
21. During the boot process, what is the sequence of events? A) Load OS, then POST, then BIOS B) BIOS, then POST, then Load OS C) POST, then Load OS, then BIOS D) Load OS, then BIOS, then POST
22. Why is a modular SMPS considered beneficial in a computer cabinet? A) It eliminates the need for a cooling fan B) It reduces internal cable clutter C) It increases processor clock speed D) It provides a wireless power connection
23. What is the primary role of the chipset on a motherboard? A) Acting as a temporary cache B) Generating the power for the CPU C) Managing data flow between processor, memory, and peripherals D) Storing the operating system files
24. Which of these is NOT a function of the BIOS/UEFI firmware? A) Initial hardware testing B) Managing system startup sequence C) Running the word processor software D) Loading the bootloader
25. What is a major advantage of PCIe over standard PCI? A) PCIe is incompatible with modern CPUs B) PCIe provides higher bandwidth and dedicated lanes C) PCIe consumes more power than PCI D) PCIe is designed only for legacy devices
26. Which of these is a common reason for a 'Disk Boot Failure' error message? A) Boot sequence is set to an empty drive B) The CPU fan is not spinning C) The RAM is overclocked D) The power supply is too large
27. When a computer is 'plug and play' compatible, what specifically does the OS do to support this? A) Only detects the hardware after a full BIOS flash B) Automatically assigns resources and loads drivers C) Requires a manual driver installation D) Blocks the hardware until the user signs in
28. Which component is most likely to be affected by the failure of a CMOS battery? A) The internet connectivity B) The printing speed C) The screen brightness D) The system time and BIOS settings
29. In the context of 'Plug and Play', what is the role of the OS? A) To physically connect the hardware to the bus B) To increase the processor voltage C) To manufacture the device driver D) To assign system resources and load correct drivers automatically
30. Which of these is NOT a typical reason for a computer failing to boot? A) Missing device driver for the mouse B) RAM module incorrectly seated C) Corrupted BIOS settings D) Defective SMPS
