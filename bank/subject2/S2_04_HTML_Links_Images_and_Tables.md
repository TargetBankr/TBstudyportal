# MOCK: Internet, HTML/DHTML and MS Office - HTML - Links, Images and Tables

## EN
1. Which HTML attribute is used to define the destination URL for a hyperlink? A) src B) link C) href D) url
2. Which tag is used to create a hyperlink in an HTML document? A) <href> B) <a> C) <url> D) <link>
3. What is the purpose of the alt attribute in an <img> tag? A) To set the image width B) To provide text for screen readers if the image fails to load C) To define the image source D) To create a border around the image
4. Which attribute is used to specify the source file path of an image? A) href B) image C) path D) src
5. Which tag is used to define a table in HTML? A) <table> B) <grid> C) <data> D) <tab>
6. Which tag represents a table row? A) <tr> B) <td> C) <trh> D) <row>
7. Which tag is used to define a standard table cell? A) <tr> B) <cell> C) <td> D) <th>
8. Which tag is used for a table header cell? A) <head> B) <h> C) <th> D) <td>
9. What attribute of the <a> tag specifies where to open the linked document? A) open B) target C) location D) window
10. Which attribute sets the width of an image in pixels? A) size B) length C) width D) scale
11. Which attribute sets the height of an image in pixels? A) tall B) vertical C) height D) size
12. Which attribute is used to merge cells across multiple columns in a table? A) colspan B) merge C) rowspan D) cols
13. What is the default value of the border attribute if not specified in an old HTML table? A) null B) 1 C) 5 D) 0
14. Which value for the target attribute opens a link in a new tab or window? A) _self B) _parent C) _blank D) _top
15. Which HTML tag is used to create a hyperlink? A) url B) href C) link D) a
16. If you want a table cell to span 3 rows, which attribute do you use? A) span="3" B) rows="3" C) colspan="3" D) rowspan="3"
17. To make an image a link, you must wrap the <img> tag inside which tag? A) <href> B) <src> C) <link> D) <a>
18. What happens if you omit the src attribute in an <img> tag? A) The browser displays a placeholder B) The tag is ignored and nothing displays C) The browser crashes D) The image appears transparent
19. Which combination correctly defines a table with one row and two cells? A) <table><tr><td></td><td></td></tr></table> B) <table><td><tr></tr></td></table> C) <table><tr><td></td></tr></table> D) <table><tr1><td1></td1><td2></td2></tr1></table>
20. If you set width="50%" for an image, what does it represent? A) 50 percent of the image file size B) 50 pixels wide C) 50 percent of the parent container width D) 50 percent of the screen height
21. What is the result of using target="_self" in an <a> tag? A) Opens the link in a new window B) Redirects to the homepage C) Opens the link in a background tab D) Opens the link in the same window
22. Which attribute is used to provide a tooltip when hovering over an image? A) alt B) info C) desc D) title
23. In a table, which tag must directly contain the <td> or <th> tags? A) <row> B) <tr> C) <border> D) <table>
24. How do you define a link that points to an email address? A) <a href="email:test@example.com"> B) <a src="test@example.com"> C) <a href="send:test@example.com"> D) <a href="mailto:test@example.com">
25. If a table cell has rowspan="2" and colspan="2", how many cells does it cover in total? A) 2 B) 3 C) 4 D) 6
26. What happens to the alt text if the image is loaded successfully? A) It remains hidden B) It displays as a tooltip C) It replaces the image D) It displays below the image
27. Which attribute is deprecated in HTML5 but was used to define table borders? A) align B) width C) border D) cellspacing
28. To create a link that jumps to a specific section on the same page, you use which attribute? A) target B) id C) link D) name
29. Which of the following is NOT a valid value for the target attribute? A) _new B) _self C) _top D) _blank
30. If you place a <table> tag directly inside a <p> tag, what is the standard behavior? A) The browser closes the p tag before the table B) The table displays correctly C) The table is ignored D) The table appears inside the text
31. What is the difference between the <th> and <td> tags? A) <th> is for headers and is bold/centered by default B) <th> is for images only C) <td> is only for the first row D) There is no difference
32. Which attribute was used to control the space between table cells in older HTML? A) margin B) cellpadding C) cellspacing D) border-spacing
33. What happens if you define a table with 3 columns but only 2 <td> cells in a row? A) The third column is omitted B) The browser adds an empty cell C) The table breaks D) The row remains incomplete
34. Is it possible to have an <a> tag without an href attribute? A) Yes, but it won't be clickable B) Yes, it acts as a placeholder or anchor C) No, it is invalid HTML D) No, it will not render
35. What is the effect of setting border="0" on a table? A) The border lines are hidden B) The cells merge C) The table width shrinks D) The table becomes invisible
36. Which attribute is used to provide a summary or description for a table in accessible web design? A) alt B) desc C) title D) summary
37. If you have nested tables, what determines the structure? A) The document root B) The parent table C) They are treated independently by the browser D) The innermost table
38. What is the correct syntax for a link that opens a document in a new window? A) <a href="url" target="_blank"> B) <a href="url" newtab="true"> C) <a href="url" open="blank"> D) <a href="url" window="new">
39. Why is the use of colspan and rowspan considered complex in large tables? A) They are not supported by mobile browsers B) They make the HTML harder to maintain C) They require CSS D) They break the grid structure
40. Which of the following is NOT a property of the <th> tag? A) It is horizontally centered by default B) It is always at the top of a table C) It indicates header information D) It is bold by default
