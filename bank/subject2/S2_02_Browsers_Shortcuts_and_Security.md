1. Which keyboard shortcut is used in most web browsers to reopen the last closed tab? A) Ctrl+Shift+T B) Ctrl+W C) Ctrl+R D) Ctrl+T

4. The HTTPS padlock icon in a browser address bar indicates that the website uses what? A) High speed servers B) A paid subscription C) No cookies D) Encryption
5. Which keyboard shortcut is used to add the current webpage to your bookmarks list? A) Ctrl+T B) Ctrl+H C) Ctrl+J D) Ctrl+D
6. In Firefox, which menu option typically contains the controls for clearing browsing history and cookies? A) Developer Tools B) Downloads C) Privacy and Security D) Sync
7. What does a padlock symbol with a warning sign usually indicate in a browser? A) The connection is not fully secure B) The website is a bookmark C) The browser is out of date D) The website is blocked by the user
8. Which of the following is the standard shortcut to view the download manager window in most browsers? A) Ctrl+D B) Ctrl+T C) Ctrl+J D) Ctrl+H
9. What is the purpose of the Firefox Options or Settings menu? A) To write HTML code B) To configure browser behavior and preferences C) To change the computer wallpaper D) To delete the browser software
10. Which keyboard shortcut is the standard way to open the browsing history sidebar or page? A) Ctrl+H B) Ctrl+W C) Ctrl+L D) Ctrl+D
11. What security information can you view by clicking on the padlock icon in the browser address bar? A) The user's IP address B) The website's source code C) The browser's memory usage D) Connection security and site certificates

14. When a browser displays a 'Your connection is not private' error, what is it usually referring to? A) The website is down for maintenance B) The user's internet is slow C) The browser cache is full D) An issue with the website's security certificate
15. Which action does Ctrl+L perform in a browser that is different from Ctrl+T? A) There is no difference between the two B) Ctrl+L selects the address bar, while Ctrl+T opens a new tab C) Ctrl+L opens a new window, while Ctrl+T opens a new tab D) Ctrl+L saves a bookmark, while Ctrl+T opens history
16. In Firefox settings, where can you manage the permission for websites to access your camera or microphone? A) Sync section B) General section C) Permissions section D) Extensions section
17. If you want to view a list of files you have downloaded during the current session, which shortcut is most efficient? A) Ctrl+H B) Ctrl+T C) Ctrl+J D) Ctrl+D
18. What is the result of using the Ctrl+W keyboard shortcut in a browser? A) Refreshes the page B) Clears the cache C) Opens a new window D) Closes the current tab

21. In the context of browser security, what does a 'Mixed Content' warning mean? A) The page is secure but includes non-secure elements like images B) The website uses multiple search engines C) The website is blocked by the firewall D) The browser has detected a virus
22. Which of the following browser shortcuts is correctly matched with its function? A) Ctrl+L: Delete history B) Ctrl+W: Refresh page C) Ctrl+T: Open downloads D) Ctrl+D: Bookmark this page
23. When using the browser, what is the effect of pressing Ctrl+L followed by typing a web address? A) The current page is replaced by the new address B) The new address opens in a new tab C) The browser crashes D) The address is saved to bookmarks
24. Which setting in Firefox allows you to control whether the browser automatically saves your form data? A) Network Settings B) Privacy and Security C) Forms and Autofill D) General Preferences
25. Why is it considered safer to use HTTPS instead of HTTP when browsing? A) HTTPS prevents the browser from crashing B) HTTPS encrypts the data transmitted between the browser and the server C) HTTPS allows the website to store more cookies D) HTTPS makes the website load faster
26. If a user wants to check if their browser is configured to block pop-ups, where should they look? A) Bookmarks manager B) Privacy and Security settings C) History page D) Downloads page
27. Which key combination would you use if you are in a web page and want to move focus to the address bar without using a mouse? A) Ctrl+L B) Ctrl+H C) Ctrl+B D) Ctrl+J
28. What is the primary risk of ignoring a 'Certificate Authority' invalid warning in a browser? A) Potential interception of sensitive information B) The website will not be able to display images C) The browser may lose internet connectivity D) The computer's hard drive might be erased
29. In Firefox, if you want to prevent websites from tracking your browsing activity, which settings menu should you access? A) Sync settings B) Developer settings C) Enhanced Tracking Protection D) Appearance settings
30. Which of the following is NOT a standard shortcut in modern web browsers? A) Ctrl+T B) Ctrl+W C) Ctrl+S+T D) Ctrl+H
31. When you press Ctrl+Shift+T, if there are no previously closed tabs to restore, what happens? A) The browser closes B) Nothing occurs C) A new tab opens D) The history page opens
32. If you are on a webpage and press Ctrl+L then press Enter without typing anything, what is the most likely behavior? A) A new blank page opens B) The current page reloads C) The address bar is cleared D) The browser closes
