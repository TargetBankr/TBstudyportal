16. Which category of animation effects is used to make an object disappear? A) Entrance B) Motion Path C) Emphasis D) Exit

24. Which key should be pressed during a slide show to toggle the screen to black? A) P B) B C) N D) W

26. In the 'Custom Animation' pane, what does the number next to an object indicate? A) The size of the object B) The slide number C) The order in which the animation will play D) The duration of the animation
27. Which of these actions is NOT possible during a PowerPoint slide show? A) Changing the slide layout B) Clearing annotations C) Skipping to a specific slide D) Drawing with a pen tool
28. When using 'Rehearse Timings', where are the recorded times stored? A) In a separate text file B) As a property of each slide C) In the Slide Master D) They are not saved
29. In the context of 'Effect Options' for an animation, what does 'Animate text: By letter' do? A) Highlights each letter in a different color B) Animates each letter of the text box individually C) Changes the font of the letters D) Makes the whole paragraph appear at once
30. Which of the following is NOT a timing option in the Animation pane? A) Duration B) Repeat C) Start On Click D) Delay
