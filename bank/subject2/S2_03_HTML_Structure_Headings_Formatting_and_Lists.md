# MOCK: Internet, HTML/DHTML and MS Office - HTML - Structure, Headings, Formatting and Lists

## EN
1. Which HTML tag is used to define the root of an HTML document? A) <title> B) <body> C) <head> D) <html>
2. Which section of an HTML document typically contains metadata and the page title? A) <head> B) <body> C) <header> D) <footer>
3. Which tag is used to display the title of the webpage in the browser tab? A) <header> B) <title> C) <head> D) <meta>
4. The visible content of an HTML document is contained within which tag? A) <main> B) <display> C) <body> D) <visible>
5. Which heading tag represents the largest and most important heading? A) <h1> B) <h> C) <h6> D) <h0>
6. Which tag is used to insert a single line break in HTML? A) <break> B) <lb> C) <br> D) <newline>
7. Which tag represents the smallest heading level? A) <h16> B) <hsmall> C) <h6> D) <h6-small>
8. Which tag is used to create a horizontal rule or line across a page? A) <hr> B) <break-line> C) <rule> D) <line>
9. Which HTML tag is used to define a paragraph of text? A) <line> B) <text> C) <p> D) <para>
10. Which tag makes text appear bold without emphasizing its importance? A) <bold> B) <text-bold> C) <strong> D) <b>
11. Which tag represents italicized text? A) <italic> B) <it> C) <slant> D) <i>
12. Which HTML tag is used to underline text? A) <u> B) <under> C) <un> D) <line-under>
13. Which tag is used to define an ordered list? A) <ul> B) <order> C) <ol> D) <list>
14. Each item within an unordered or ordered list must be wrapped in which tag? A) <li> B) <list> C) <item> D) <i>
15. Which tag is used to define a subscript character? A) <sb> B) <sub> C) <down> D) <subscript>
16. Which tag is used to define a superscript character? A) <up> B) <sup> C) <sp> D) <super>
17. What is the purpose of the <mark> tag in HTML? A) To highlight text B) To italicize text C) To underline text D) To bold text
18. Which tag is semantically used to define important text? A) <b> B) <strong> C) <important> D) <imp>
19. Which tag is used to provide emphasis to text, usually rendering it as italics? A) <em> B) <italic> C) <accent> D) <emp>
20. What happens if you place a <br> tag inside a <p> tag? A) The tag is ignored by the browser B) The text after <br> is moved to a new list item C) The paragraph splits into two separate paragraphs D) A line break occurs within the same paragraph
21. What is the default bullet style for an unordered list (<ul>)? A) Square B) Circle C) Disc D) None
22. What does the tag <strong> do in HTML? A) Makes text italic B) Adds importance to text C) Makes text bold D) Creates a heading
23. How many levels of headings are available in standard HTML? A) 3 B) 5 C) 6 D) 8
24. If you want to create a list where the order does not matter, which tag should you use? A) <list> B) <ol> C) <dl> D) <ul>
25. What happens to the text if you wrap it in both <b> and <i> tags? A) It becomes bold and underlined B) It becomes italicized and underlined C) It becomes bold and italicized D) It becomes bold and highlighted
26. Which tag is used to create a description list? A) <ul> B) <dl> C) <list> D) <ol>
27. What is the primary difference between <b> and <strong>? A) <b> is for styling, <strong> conveys semantic importance B) <b> is deprecated and <strong> is the modern replacement C) <b> is for bold, <strong> is for stronger bold D) They behave exactly the same in all browsers
28. Which attribute is required for an ordered list to start with a specific number? A) index B) start C) value D) begin
29. In an HTML document, which tag must always be the first line? A) <html> B) <!DOCTYPE html> C) <head> D) <body>
30. What is the correct way to nest a list item inside an unordered list? A) <ul><item>text</item></ul> B) <list><li>text</li></list> C) <ul text='li'> D) <ul><li>text</li></ul>
31. Which tag is used to define a term in a description list? A) <term> B) <dl-item> C) <dt> D) <dd>
32. Which tag is used to provide the description for a term in a description list? A) <dl-desc> B) <dt> C) <description> D) <dd>
33. Which of the following tags is NOT a block-level element? A) <ul> B) <p> C) <em> D) <h1>
34. If you place a <ul> inside another <ul>, what is this process called? A) Grouping B) Linking C) Looping D) Nesting
35. Which of the following tags does not require a closing tag in HTML? A) <p> B) <strong> C) <ul> D) <hr>
36. Which of these is the correct hierarchy for headings in a document? A) <h10> to <h16> B) <h1> to <h6> C) <h1> to <h5> D) <h1> to <h9>
37. In an ordered list, which attribute is used to change the bullet style to letters or Roman numerals? A) format B) order C) type D) style
38. Why is the <title> tag placed inside the <head> tag and not the <body> tag? A) Because it is metadata for the document B) Because it is a block element C) Because it contains images D) Because it needs to be bold
39. Which of the following is an invalid nesting of tags in HTML? A) <b><p>text</p></b> B) <ul><li><b>text</b></li></ul> C) <em><strong>text</strong></em> D) <p><b>text</b></p>
