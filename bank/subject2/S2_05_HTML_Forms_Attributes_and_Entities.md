20. If you want to disable an input field so the user cannot interact with it, which attribute is used? A) disabled B) readonly C) inactive D) hidden

31. When using the POST method in a form, where is the submitted data sent? A) as a browser cookie B) in the HTTP request body C) in the URL D) to the local cache
